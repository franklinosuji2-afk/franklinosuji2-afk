# Franklin Osuji

Cloud and DevOps engineer based in Berlin with almost 4 years of professional experience delivering AWS and Azure infrastructure as code, containerized workloads and CI/CD pipelines for contract and client environments, plus a 2.5-year apprenticeship and 1 year of work-study since 2019.

I work across the full delivery path: Terraform-provisioned infrastructure, Jenkins and GitHub Actions pipelines, ECS/Fargate and Kubernetes deployments, and Prometheus, Grafana and Loki for observability. In personal projects I build platform tooling, including a local Kubernetes platform with Argo CD GitOps, a Compose-based Prometheus, Grafana and Loki stack and Trivy scanning in CI.

My background is petroleum engineering, where a small miscalculation has large consequences. I carry that habit into infrastructure: think in systems, respect constraints, and ask what a change depends on before touching it. The goal is infrastructure that is repeatable, secure and does not need a hero to keep it running.

AWS Certified Cloud Practitioner, preparing to sit the HashiCorp Terraform Associate and AWS Solutions Architect Associate exams. Completed the AWS Cloud Engineer program at DCI Berlin. English native, German B2. 


📍Open to hybrid and remote Cloud, DevOps, Platform and SRE roles in Berlin, Germany and the EU
